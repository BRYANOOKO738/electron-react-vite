# Download

Get the latest version from the
[releases page](https://github.com/BRYANOOKO738/electron-react-vite/releases/latest).

| System  | File to download                                 |
| ------- | ------------------------------------------------ |
| Windows | `...Setup.exe`                                   |
| macOS   | `...darwin-*.zip`                                |
| Linux   | `.deb` (Debian, Ubuntu) or `.rpm` (Fedora, RHEL) |

::: warning
The installers are not code-signed yet, so Windows SmartScreen and macOS Gatekeeper may warn you
when you open them.
:::
